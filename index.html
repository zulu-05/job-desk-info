Personal Windows application

A local workspace for a personal job search.

Job Desk helps its owner organise job and apprenticeship opportunities, application records, documents, follow-ups and employer replies on their own computer.

Optional Gmail connection

With the account holder’s permission, the desktop application connects directly to Google’s Gmail API using read-only access. A configurable search chooses which messages to import for local review and matching to saved applications.

The application does not send email, mark messages read, change labels, archive or delete Gmail messages. Imported message content is excluded from requests to external AI providers.

These are information pages

This website does not provide mailbox access, account registration, an application download or a hosted job dashboard. It contains no CVs, job-search records, messages or credentials. The desktop app is maintained for its owner’s personal use.

Read the privacy policy and personal-use terms. For questions about a Google authorisation, use the support address displayed on that authorisation screen.
